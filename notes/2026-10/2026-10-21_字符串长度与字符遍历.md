## 1. 字符串可以按位置读，但不是数组

| 操作 | int[]数组a | String字符串s |
| --- | --- | --- |
| 长度 | a.length | s.length() |
| 读第i项 | a[i] | s.charAt(i) |
| 最后合法下标 | a.length−1 | s.length()−1 |
| 修改原内容 | 可给a[i]赋值 | String不可变，不能给charAt结果赋值 |

`"Java"` 的下标为0到3；`charAt(4)`越界。空串`""`的length()是0，没有合法下标。不要在判断是否为空之前直接访问第0位。

Java按UTF-16的char单元计长度、定下标；大部分本练习英文符号各占一项，但“😀”占两项。今天只做char扫描，不把结果称作可见字符数，也不引入额外的Unicode处理算法。

## 2. 先想边界，再写循环

目标是数出小写'a'的个数。遍历条件写 `i < text.length()`，每次读一个char。空串会自然跳过，不需要先访问第一项。

`'a'`是char，`"a"`是String。字符比较可以用==；不要由此推导字符串内容也应该用==。空格也是内容，不随意trim；大写A不等于小写a。

## 3. 最小可运行程序

保存为`TextScan.java`，运行`javac TextScan.java`，然后`java TextScan`。输入一整行文本，空行是合法的空串；不是缺失的输入流。使用nextLine保留空格，不会只读第一个单词。

```java
import java.util.Scanner;

public class TextScan {
    // 前提：text 非 null；本练习按 UTF-16 char 单元处理。
    static int countChar(String text, char target) {
        int count = 0;
        for (int i = 0; i < text.length(); i++) {
            if (text.charAt(i) == target) {
                count++;
            }
        }
        return count;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String text = sc.nextLine();
        System.out.println("Length: " + text.length());
        System.out.println("a: " + countChar(text, 'a'));
    }
}
```

输入`Java data`：

```text
Length: 9
a: 4
```

输入空行：

```text
Length: 0
a: 0
```

输入` a A `（保留首尾空格）：

```text
Length: 5
a: 1
```

正常计数、空串、单字符、无目标及UTF-16边界在配套短练习中均有固定自测。

## 4. 时间与空间

设n为UTF-16 char单元数。常规JDK字符串索引模型下，countChar查看n项，时间O(n)，额外空间O(1)。它不复制字符串；主程序输入字符串本身的存储另占O(n)。即使找到一个a也不能立即返回，因为要统计所有出现次数。

## ⚠️ 易错点

| 错误 | 为什么错 |
| --- | --- |
| s.length、s[i] | 把数组语法搬给String |
| i<=s.length() | 会访问不存在的最后位置 |
| 空串先charAt(0) | 空串没有第0项 |
| 为方便而trim输入 | 改变原文本长度与空格内容 |
| 找到第一个a就return | 那是首次查找，不是全部计数 |
