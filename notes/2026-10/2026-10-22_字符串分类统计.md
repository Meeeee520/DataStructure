## 1. 一次扫描，四个互斥类别

返回 `int[4]`，下标依次表示 ASCII 英文字母、ASCII 数字、普通空格、其他。使用 `if / else if / else` 保证每个 char 单元只进入一个类别。

这是明确约定的 ASCII 练习，不等于完整的 Unicode 文字分类；例如汉字进入“其他”。Java String 按 UTF-16 char 单元索引，今天不扩展 code point 算法。

## 2. 可运行示例

```java
import java.util.Arrays;
import java.util.Scanner;

public class TextCategories {
    static int[] countAsciiCategories(String text) {
        int[] counts = new int[4]; // letters, digits, spaces, others
        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            if ((ch >= 'A' && ch <= 'Z') || (ch >= 'a' && ch <= 'z')) {
                counts[0]++;
            } else if (ch >= '0' && ch <= '9') {
                counts[1]++;
            } else if (ch == ' ') {
                counts[2]++;
            } else {
                counts[3]++;
            }
        }
        return counts;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println(Arrays.toString(countAsciiCategories(sc.nextLine())));
    }
}
```

输入 `A1 b!` 输出 `[2, 1, 1, 1]`；空行输出 `[0, 0, 0, 0]`；输入 `你a` 输出 `[1, 0, 0, 1]`。一次扫描时间 O(n)，固定四项数组使额外空间 O(1)。

## ⚠️ 易错点

| 错误 | 纠正 |
| --- | --- |
| 四个独立 if | 若条件重叠可能重复计数；本题用互斥链 |
| 把所有空白都当普通空格 | 本契约只认 `ch == ' '` |
| 声称统计所有“字符” | 本练习统计 UTF-16 char 单元 |
| 每类另扫一次 | 一次扫描即可 |
