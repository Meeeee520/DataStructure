## 🔄 一、什么叫“遍历数组”

遍历就是按照某种顺序把数组中的每一项访问一次。昨天我们手动写 `scores[0]`、`scores[1]`；当数组很长或长度在运行时才知道时，应交给循环。

```java
int[] scores = {78, 92, 85};

for (int i = 0; i < scores.length; i++) {
    System.out.println(scores[i]);
}
```

输出：

```text
78
92
85
```

普通 `for` 的三部分：

```java
for (int i = 0; i < scores.length; i++)
```

| 部分 | 含义 |
| --- | --- |
| `int i = 0` | 从第一个有效下标 0 开始 |
| `i < scores.length` | 只要下标仍在有效范围内就继续 |
| `i++` | 每轮后移动到下一个下标 |

边界必须写 `<`，不是 `<=`。长度为 3 时有效下标只有 0、1、2；若允许 `i == 3`，访问 `scores[3]` 就会越界。

## 🧺 二、增强 for：直接取出每个值

不需要下标时，可以写得更简洁：

```java
int[] scores = {78, 92, 85};

for (int score : scores) {
    System.out.println(score);
}
```

读作：“对于 `scores` 中的每一个 `int` 值，把本轮的值放进变量 `score`。”

| 需求 | 更合适的写法 |
| --- | --- |
| 只读取每个值并累加 | 增强 `for` |
| 需要显示下标 | 普通 `for` |
| 需要修改指定数组元素 | 普通 `for`，写 `a[i] = ...` |
| 需要同时看相邻元素 | 普通 `for`，小心边界 |

### 为什么给 for-each 变量赋值不改数组？

```java
int[] a = {2, 4};

for (int x : a) {
    x = 9;
}

System.out.println(a[0] + " " + a[1]);
```

输出仍是：

```text
2 4
```

每一轮都把某个数组元素的 **int 值复制**给局部变量 `x`。`x = 9` 只是改这个局部变量；它没有写回 `a[0]` 或 `a[1]`。

若要把所有元素改成 9，需要下标：

```java
for (int i = 0; i < a.length; i++) {
    a[i] = 9;
}
```

这里讨论的是基本类型 `int`。后面学习对象数组和引用时，“修改对象内部”与“给循环变量重新赋引用”还要进一步区分。

## 📊 三、总和与平均值

### 1. 用累加器保存到目前为止的结果

```java
int[] scores = {78, 92, 85, 60};
int sum = 0;

for (int score : scores) {
    sum += score;
}

System.out.println(sum);
```

输出 `315`。`sum` 必须在循环外初始化，否则每一轮都会重新开始，循环结束后也可能无法使用它。

### 2. 避免整数除法

```java
double average = (double) sum / scores.length;
```

若 `sum` 和 `scores.length` 都是 `int`，先做整数除法会丢掉小数。例如 `5 / 2` 是 2；写 `(double) 5 / 2` 才得到 2.5。

不过，在除法前还有更重要的一步：数组可能为空。空数组的长度是 0，不能直接除以 0。

## 📈 四、最大值与最小值

对于非空数组，最稳妥的起点是数组的第一个元素：

```java
int min = scores[0];
int max = scores[0];

for (int score : scores) {
    if (score < min) {
        min = score;
    }
    if (score > max) {
        max = score;
    }
}
```

不要随手把 `max` 设为 0。如果数组是 `{-8, -3, -10}`，真实最大值是 -3，而 0 根本不在数组里。

但 `scores[0]` 只对非空数组合法，所以完整顺序是：

1. 先检查 `scores.length == 0`。
2. 非空时再读取 `scores[0]`。
3. 遍历并更新总和、最小值、最大值。
4. 最后计算平均值。

## 💻 五、完整示例：一次遍历完成统计

将下面代码保存为 `GradeStats.java`：

```java
public class GradeStats {
    public static void main(String[] args) {
        int[] scores = {78, 92, 85, 60};

        if (scores.length == 0) {
            System.out.println("No data");
        } else {
            int sum = 0;
            int min = scores[0];
            int max = scores[0];

            for (int score : scores) {
                sum += score;

                if (score < min) {
                    min = score;
                }
                if (score > max) {
                    max = score;
                }
            }

            double average = (double) sum / scores.length;
            System.out.println("Sum: " + sum);
            System.out.printf(java.util.Locale.ROOT,
                    "Average: %.2f%n", average);
            System.out.println("Min: " + min);
            System.out.println("Max: " + max);
        }
    }
}
```

输出：

```text
Sum: 315
Average: 78.75
Min: 60
Max: 92
```

`java.util.Locale.ROOT` 让小数点稳定显示为 `.`。今天只需会使用这一行，不要求学习 `Locale` 的细节。

把数组改为 `int[] scores = {};`，程序输出：

```text
No data
```

它不会访问不存在的 `scores[0]`，也不会除以 0。

### 一次遍历中发生了什么？

| 当前 `score` | `sum` | `min` | `max` |
| ---: | ---: | ---: | ---: |
| 初始 | 0 | 78 | 78 |
| 78 | 78 | 78 | 78 |
| 92 | 170 | 78 | 92 |
| 85 | 255 | 78 | 92 |
| 60 | 315 | 60 | 92 |

这种“读到一个值，就更新已有统计量”的方式不需要额外数组，且只访问每项一次。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| 循环条件应写 `i <= a.length` | `a.length` 本身已经越界 | 写 `i < a.length` |
| `for (int x : a)` 中 `x = 9` 会改数组 | `x` 得到的是当前 int 值的副本 | 修改用 `a[i] = 9` |
| `sum` 应在循环里设为 0 | 这样每轮都会清空之前结果 | 在循环前初始化一次 |
| `double avg = sum / length` 一定保留小数 | 两个 int 会先做整数除法 | `(double) sum / length` |
| 最大值初始设为 0 总是安全 | 全为负数时会得到错误结果 | 非空后用 `a[0]` 初始化 |
| 空数组也有第一个元素 | 长度 0 时没有任何有效下标 | 先检查 `a.length == 0` |
| for-each 总是更好 | 需要下标或写回元素时不合适 | 根据任务选择循环 |

### 练习 3 · 统计高于平均分的人数（进阶）

对 `{60, 80, 100}`，先算平均分，再进行第二次遍历，统计严格高于平均分的元素数量。

<details>
<summary>查看参考答案</summary>

```java
int[] scores = {60, 80, 100};
int sum = 0;

for (int score : scores) {
    sum += score;
}

double average = (double) sum / scores.length;
int aboveAverage = 0;

for (int score : scores) {
    if (score > average) {
        aboveAverage++;
    }
}

System.out.println(aboveAverage);
```

平均分是 80，只有 100 严格高于平均分，所以输出 1。先知道平均分，才能判断每一项是否高于它，因此这里自然使用两次遍历。

</details>
