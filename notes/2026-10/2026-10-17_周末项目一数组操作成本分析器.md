## 1. 容量不等于有效长度

```java
int[] values = new int[6];
int size = 4;
values[0] = 10;
values[1] = 20;
values[2] = 30;
values[3] = 40;
```

- `values.length` 是容量 6，创建后固定。
- `size` 是当前真正保存的元素个数 4。
- 有效数据下标是 `0` 到 `size - 1`；下标 4、5 只是空余容量。

如果查找时遍历到 `values.length`，空余位置里的默认值 `0` 可能被误认为真实数据。

## 2. 查找并记录检查次数

```java
static int[] findWithChecks(int[] values, int size, int target) {
    for (int i = 0; i < size; i++) {
        if (values[i] == target) {
            return new int[]{i, i + 1};
        }
    }
    return new int[]{-1, size};
}
```

返回值 `{index, checks}`：

- 第一个位置命中：`{0, 1}`。
- 最后一个位置命中：检查 `size` 次。
- 不存在：也检查 `size` 次，返回下标 `-1`。

最好时间是 `O(1)`，最坏时间是 `O(n)`；其中 `n = size`。

## 3. 中间插入为什么要右移

当前有效内容：

```text
[10, 20, 30, 40, _, _]
```

在下标 1 插入 15，必须**从右向左**移动：

```text
40 → 下标 4
30 → 下标 3
20 → 下标 2
15 → 下标 1
```

结果：

```text
[10, 15, 20, 30, 40, _]
```

如果从左向右移动，`20` 会先覆盖 `30`，后面的原值就丢失。

```java
static int insertAt(int[] values, int size, int index, int value) {
    if (size == values.length || index < 0 || index > size) {
        return -1;
    }
    int shifts = 0;
    for (int i = size; i > index; i--) {
        values[i] = values[i - 1];
        shifts++;
    }
    values[index] = value;
    return shifts;
}
```

插入末尾移动 0 次，是 `O(1)`；插入开头最多移动 `n` 次，最坏是 `O(n)`。

## 4. 删除为什么要左移

删除下标 2 后，右侧元素要向左填补空洞：

```java
static int deleteAt(int[] values, int size, int index) {
    if (index < 0 || index >= size) {
        return -1;
    }
    int shifts = 0;
    for (int i = index; i < size - 1; i++) {
        values[i] = values[i + 1];
        shifts++;
    }
    values[size - 1] = 0;
    return shifts;
}
```

删除最后一项移动 0 次；删除开头最多移动 `n - 1` 次，最坏是 `O(n)`。

## ⚠️ 易错点辨析

| 常见错误 | 后果 | 修正 |
| --- | --- | --- |
| 把 `values.length` 当成有效数据数量 | 读到空余位置的默认值 | 单独维护 `size` |
| 插入时从左向右移动 | 后面的原值被覆盖 | 从 `size` 向 `index` 倒序移动 |
| 满容量仍插入 | 写入 `values[length]` 越界 | 先检查 `size == length` |
| 允许 `index > size` 插入 | 有效数据中间出现空洞 | 插入位置限定 `0 <= index <= size` |
| 删除后忘记 `size--` | 旧尾值仍被视为有效 | 成功后更新有效长度 |
| 只给最坏复杂度，不解释移动次数 | 结论无法验证 | 写清 `n - index` 或 `n - index - 1` |
