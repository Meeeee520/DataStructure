## 1. 两个验收任务

`adjacentEquals(values,size)` 只看前 size 项，从 i=1 开始比较 `values[i]` 与前一项。`[2,2,5,5,5]` 有3对：一对2、两对5。不要把三个相同元素误算成3对或1对。

`countLowercaseVowels(text)` 扫描所有 char，只统计小写 a/e/i/o/u；大小写规则写进契约，不偷偷转小写。两个方法均为单次扫描，时间分别 O(size) 与 O(text.length())，额外空间 O(1)。

## 2. 可运行验收程序

```java
import java.util.Arrays;
import java.util.Scanner;

public class ArrayStringCheck {
    static int adjacentEquals(int[] values, int size) {
        int count = 0;
        for (int i = 1; i < size; i++) {
            if (values[i] == values[i - 1]) count++;
        }
        return count;
    }

    static int countLowercaseVowels(String text) {
        int count = 0;
        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') {
                count++;
            }
        }
        return count;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int capacity = sc.nextInt();
        int size = sc.nextInt();
        if (capacity < 0 || size < 0 || size > capacity) {
            System.out.println("Invalid model");
            return;
        }
        int[] values = new int[capacity];
        for (int i = 0; i < size; i++) values[i] = sc.nextInt();
        sc.nextLine();
        String text = sc.nextLine();
        System.out.println("Adjacent: " + adjacentEquals(values, size));
        System.out.println("Vowels: " + countLowercaseVowels(text));
        System.out.println("Active: " + Arrays.toString(Arrays.copyOf(values, size)));
    }
}
```

正常输入：

```text
6 5
2 2 5 5 5
education
```

输出：

```text
Adjacent: 3
Vowels: 5
Active: [2, 2, 5, 5, 5]
```

容量0、size0、空文本得到两个0；size 超过容量在读取数据前输出 `Invalid model`。显示有效区间使用 `copyOf` 会建立副本，这部分输出空间另算 O(size)。

## ⚠️ 易错点

| 错误 | 纠正 |
| --- | --- |
| 从 i=0 访问 i-1 | 相邻比较从1开始 |
| 扫描整个 capacity | 只扫描有效区间 size |
| 三个相同值只算一组 | 相邻对按边计数，三个连续值有两对 |
| 自动转小写 | 改变了本题只数小写的契约 |
