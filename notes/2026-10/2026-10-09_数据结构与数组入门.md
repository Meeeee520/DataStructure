## 🧠 数据结构是什么

如果只记录一门成绩，可以用 `int score = 80;`。记录多门成绩时，分别写 `score1`、`score2`、`score3` 很快就不好管理。数组把这些同类数据组织在一起，让你用下标选择某个元素。

数据结构关心“数据怎样放、怎样访问、怎样修改”；算法则关注“为了完成任务，按什么步骤操作这些数据”。今天只从数组这一个结构开始。

| 问题 | 今天的数组做法 | 后续会学什么 |
| --- | --- | --- |
| 想知道第 2 项 | 用下标 1 读取 | 下标访问与查找的区别 |
| 想改第 2 项 | 给下标 1 赋新值 | 更新与插入的区别 |
| 想多放一项 | 原数组长度不能直接变长 | 顺序表、动态数组与扩容 |
| 想按进入顺序处理 | 数组只负责保存，规则另定 | 栈与队列 |

## 🔢 元素、下标与长度

```java
int[] scores = {80, 90, 100};
```

| 下标 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 元素的值 | 80 | 90 | 100 |
| 日常说法 | 第 1 项 | 第 2 项 | 第 3 项 |

- `scores.length` 是 3，即元素总数。
- `scores[1]` 是 90，即下标 1 对应的值。
- 最后一个有效下标是 `scores.length - 1`，此处为 2。
- `scores[3]` 越界，不能把长度当成末项下标。

### 声明与创建要分清

```java
int[] values;
values = new int[3];
```

第一句声明一个能引用整数数组的变量；第二句才创建数组并把引用交给它。`new int[3]` 创建的是 3 个元素，不是把数字 3 存进去。

创建以后，这个数组对象的长度固定。重新执行 `values = new int[5];` 会让变量引用另一个数组，不是把原数组扩长，旧数据也不会自动搬过去。具体的引用与复制将在 10 月 11 日练。

`int[] empty = new int[0];` 是合法的空数组，长度为 0；它没有第一个元素，不能访问 `empty[0]`。

## 💻 跟着运行：读取和更新

将下面完整程序保存为 `ArrayBasics.java`，文件名与公开类名相同。Mac 终端进入文件所在文件夹后，如果安装了 Java 11 或更新的 JDK，可以运行 `java ArrayBasics.java`；也可以使用 `javac ArrayBasics.java` 编译，再用 `java ArrayBasics` 运行。

```java
public class ArrayBasics {
    public static void main(String[] args) {
        int[] scores = {80, 90, 100};
        scores[1] = 95;
        System.out.println("长度：" + scores.length);
        System.out.println("第一项：" + scores[0]);
        System.out.println("第二项：" + scores[1]);
        System.out.println("末项：" + scores[scores.length - 1]);
        int[] empty = new int[0];
        System.out.println("空数组长度：" + empty.length);
    }
}

```

输出：

```text
长度：3
第一项：80
第二项：95
末项：100
空数组长度：0
```

` scores[1] = 95; ` 更新了已有位置上的值，元素数仍然为 3。它既没有增加一项，也没有改动别的下标。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 小例子 |
| --- | --- | --- |
| 下标 1 是第 1 项 | Java 数组从下标 0 开始 | 第 1 项写 `a[0]` |
| 数组长度是最后一个下标 | 长度比末项下标多 1 | 长度 3，末项下标 2 |
| 更新值会改变长度 | 更新已有位置不会改变长度 | `a[1] = 7` 不增加元素 |
| `int[] a;` 已创建数组 | 它只声明局部变量 | 创建用 `new int[3]` |
| 写 `a.length()` | 数组长度是字段 | 写 `a.length` |
| 长度 0 的数组有 `a[0]` | 空数组没有有效下标 | 只能先读 `a.length` |
| 给变量赋新数组就保留旧值 | 新数组不会自动复制旧数据 | 复制需要另做操作 |
| Java 数组就是 Python 列表 | 两者长度行为不同 | Java 数组对象长度固定 |

遇到 `ArrayIndexOutOfBoundsException`，先检查下标是不是小于 0，或者大于等于数组长度。今天先认识边界，不要求写异常捕捉。

### 1. 看图式表格，写出对应值

对于 `int[] a = {6, 10, 15};`，分别写出 `a.length`、`a[0]`、`a[a.length - 1]` 的值。

<details>
<summary>查看答案</summary>

依次是 `3`、`6`、`15`。长度是数量，下标用来选择位置。

</details>

### 2. 更新末项

创建 `{80, 90, 100}`，把最后一项更新为 `99`，再输出长度和末项。不要把数组长度写死在末项访问里。

<details>
<summary>查看参考答案</summary>

```java
int[] scores = {80, 90, 100};
scores[scores.length - 1] = 99;
System.out.println(scores.length);
System.out.println(scores[scores.length - 1]);
```

输出：

```text
3
99
```

</details>

### 3. 辨析两个边界

`int[] a = new int[0];` 时，读 `a.length` 和读 `a[0]` 分别会怎样？如果数组长度改成 1，读 `a[1]` 是否合法？

<details>
<summary>查看答案</summary>

空数组的 `a.length` 为 0，但 `a[0]` 越界。长度为 1 时，唯一有效下标是 0，`a[1]` 仍然越界。有效范围是 `0 <= 下标 < a.length`。

</details>
