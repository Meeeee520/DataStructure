## 1. 有空位，不代表每个空位都能直接插

```java
int[] values = {0, 8, 0, 0, 0};
int size = 3;
```

容量 `values.length` 为 5，有效数据是前 3 项 `[0, 8, 0]`。两个 0 都可以是真实数据；不能根据数值是否为 0 判断一个位置是否有效。

| 想做的事 | 合法范围 |
| --- | --- |
| 读取或删除有效元素 | `0 <= index < size` |
| 在有效序列中插入 | `0 <= index <= size`，且 `size < values.length` |
| 追加到末尾 | `index == size`，并且还有容量 |

这里在下标 3 插入是尾插；在下标 4 直接写入会留下一个不属于有效序列的空洞，不能当作本模型的合法插入。合法性既要看容量，也要看有效长度。

## 2. 中间插入：先右移，再填空位

有效数据 `[10, 20, 30]` 在下标 1 插入 15，容量至少为 4：

1. 原下标 2 的 30 移到下标 3。
2. 原下标 1 的 20 移到下标 2。
3. 下标 1 写入 15。

一共移动 `size - index = 3 - 1 = 2` 次。必须从右往左处理，否则先移动 20 会覆盖后面还没保存的 30。

## 3. 完整可运行示例

保存为 `InsertionPractice.java`。输入容量、有效长度、有效元素、插入下标及值；容量与长度必须是合法整数，成绩值在此仅作为普通整数处理。运行 `javac InsertionPractice.java`，再运行 `java InsertionPractice`。

```java
import java.util.Arrays;
import java.util.Scanner;

public class InsertionPractice {
    // 前提：values 非 null，0 <= size <= values.length。
    static int insertAt(int[] values, int size, int index, int value) {
        if (size == values.length || index < 0 || index > size) {
            return -1;
        }
        int shifts = 0;
        for (int i = size; i > index; i--) {
            values[i] = values[i - 1];
            shifts++;
        }
        values[index] = value;
        return shifts;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int capacity = sc.nextInt();
        int size = sc.nextInt();
        if (capacity < 0 || size < 0 || size > capacity) {
            System.out.println("Invalid model");
            return;
        }
        int[] values = new int[capacity];
        for (int i = 0; i < size; i++) {
            values[i] = sc.nextInt();
        }
        int index = sc.nextInt();
        int value = sc.nextInt();
        int shifts = insertAt(values, size, index, value);
        if (shifts >= 0) {
            size++;
        }
        System.out.println("Shifts: " + shifts);
        System.out.println("Size: " + size);
        System.out.println("Values: " + Arrays.toString(Arrays.copyOf(values, size)));
    }
}
```

正常输入：

```text
5 3
10 20 30
1 15
```

输出：

```text
Shifts: 2
Size: 4
Values: [10, 15, 20, 30]
```

空序列有容量时，输入 `2 0 0 0`，表示容量 2、有效长度 0、在下标 0 插入真实值 0，输出：

```text
Shifts: 0
Size: 1
Values: [0]
```

返回值是移动次数，不是新长度。`0` 是成功，`-1` 才是失败。方法中的整数参数 `size` 是副本，调用者在成功后自行 `size++`；数组元素的修改则能通过共享引用看到。这个返回约定与周末项目保持一致。

## 4. 成本与边界

以 `n = size` 分析核心插入方法：尾插移动 0 次，时间 O(1)；首插移动 n 次，最坏 O(n)；原地移动只用固定数量变量，额外工作空间 O(1)。满容量或非法位置在检查后返回，失败不改数据。

`Arrays.copyOf` 在这里仅用于展示有效序列，会另建长度为 n 的数组，额外占 O(n) 空间；不能把包含展示副本的整段程序也说成额外 O(1)。

| 边界 | 应有行为 |
| --- | --- |
| `size == 0` 且容量大于 0 | 允许在下标 0 插入 |
| `index == size` 且有空位 | 尾插成功，移动 0 次 |
| `size == capacity`，包括容量 0 | 返回 -1，不越界、不增 size |
| `index < 0` 或 `index > size` | 返回 -1，不留下空洞 |
| 有效元素中含 0 或重复值 | 正常移动；有效区间只由 size 决定 |

## ⚠️ 易错点

| 错误 | 后果 | 修正 |
| --- | --- | --- |
| 把数组 length 当作 size | 空余位置被当作数据 | 独立维护有效长度 |
| 插入条件写 `index < size` | 错误拒绝合法尾插 | 插入允许 `index == size` |
| 往右移动时从左开始 | 覆盖还没复制的元素 | 从右向左移动 |
| 判断 `shifts > 0` 才增长度 | 尾插成功但长度未变 | 判断 `shifts >= 0` |
| 满容量仍先移动再检查 | 访问下标 length 越界 | 所有修改前先校验 |
| 不规则二维数组统一用首行长度 | 可能越界或漏掉元素 | 内层看当前行的 length |
