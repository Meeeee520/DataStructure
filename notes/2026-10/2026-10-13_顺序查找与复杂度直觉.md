## 🎯 今日目标

- 理解顺序查找就是从下标 0 开始逐个比较。
- 找到目标时返回第一次出现的下标；不存在时返回 `-1`。
- 会用 `return` 提前结束查找。
- 能追踪实际比较次数，理解最好情况与最坏情况。
- 知道长度为 `n` 的数组，最坏需要检查 `n` 个元素，所以成本随 `n` 线性增长，记作 `O(n)`。
- 能正确处理空数组、单元素、重复值和目标不存在。

## 1. 顺序查找在做什么

数组没有排序时，目标可能在任何位置。最直接的方法是：

1. 从 `a[0]` 开始。
2. 当前元素等于目标就立即返回下标。
3. 一直走到数组末尾仍没找到，就返回 `-1`。

```java
static int findFirst(int[] a, int target) {
    for (int i = 0; i < a.length; i++) {
        if (a[i] == target) {
            return i;
        }
    }
    return -1;
}
```

`-1` 不会与合法下标冲突，因为 Java 数组下标从 0 开始。

## 2. 为什么找到后立刻 `return`

```java
int[] scores = {72, 88, 60, 88};
System.out.println(findFirst(scores, 88));
System.out.println(findFirst(scores, 100));
```

输出：

```text
1
-1
```

目标 `88` 出现两次，但函数在下标 1 找到后立即结束，所以返回**第一次出现的位置**。如果忘记提前结束，可能得到最后一次位置，或做无意义的额外比较。

## 3. 把比较次数也记录下来

为了看见算法做了多少工作，可以返回两个整数：下标和检查次数。

```java
static int[] searchWithCount(int[] a, int target) {
    int checks = 0;
    for (int i = 0; i < a.length; i++) {
        checks++;
        if (a[i] == target) {
            return new int[]{i, checks};
        }
    }
    return new int[]{-1, checks};
}
```

```java
int[] a = {72, 88, 60, 95};
int[] first = searchWithCount(a, 72);
int[] missing = searchWithCount(a, 100);
int[] empty = searchWithCount(new int[]{}, 50);

System.out.println(first[0] + " " + first[1]);
System.out.println(missing[0] + " " + missing[1]);
System.out.println(empty[0] + " " + empty[1]);
```

输出：

```text
0 1
-1 4
-1 0
```

空数组不会进入循环，因此自然得到下标 `-1`、检查次数 `0`。

## 4. 从次数理解 `O(n)`

设数组长度为 `n`：

| 情况 | 检查次数 | 直觉 |
| --- | ---: | --- |
| 目标在第一个元素 | 1 | 最好情况 |
| 目标在下标 `i` | `i + 1` | 先检查前面的元素 |
| 目标在最后或不存在 | `n` | 最坏情况 |

当数组长度从 10 变成 100，最坏比较次数也从 10 变成 100。工作量与 `n` 成比例，所以说最坏时间复杂度是 `O(n)`。

`O(n)` 不是“精确运行 n 秒”，也不是“程序一定很慢”；它描述输入规模变大时，工作量怎样增长。

## 5. 为什么今天不用二分查找

二分查找可以更快地排除一半数据，但前提是数组已经按要求排序。今天处理的是一般的未排序数组，因此顺序查找不要求额外准备，也能找到目标。二分查找会在后续专门学习。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| 找不到时返回 0 | 0 是合法下标 | 使用 `-1` 表示不存在 |
| 循环条件可以写 `i <= a.length` | 最后会访问 `a[a.length]` 并越界 | 写 `i < a.length` |
| 找到后仍应继续遍历 | 找第一次位置时应立即结束 | 在匹配分支中 `return i` |
| 重复值应返回最后一个位置 | 本函数约定返回第一个匹配 | 从左向右，首次匹配即返回 |
| 空数组需要访问 `a[0]` 判断 | 空数组没有下标 0 | 让循环零次执行后返回 `-1` |
| `O(n)` 表示恰好执行 n 行代码 | 它表示增长趋势 | 用比较次数随数组长度增长来理解 |
