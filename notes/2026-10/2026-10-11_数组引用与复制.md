## 🔗 一、引用赋值不是复制

```java
import java.util.Arrays;

public class ArrayReferenceDemo {
    public static void main(String[] args) {
        int[] a = {2, 4};
        int[] b = a;
        b[0] = 7;
        System.out.println(Arrays.toString(a));
        System.out.println(a == b);
    }
}
```

输出：

```text
[7, 4]
true
```

`a` 和 `b` 是两个变量，但保存的是同一个数组的引用。`b[0] = 7` 修改了共享数组，所以通过 `a` 也能看到 7。`a == b` 对数组比较的是“是否为同一个对象”，不是元素是否相同。

可以把它想成两张纸都写着同一个储物柜号码：纸有两张，柜子只有一个。

## 📦 二、复制一维数组

### 1. `Arrays.copyOf`

```java
import java.util.Arrays;

public class ArrayCopyDemo {
    public static void main(String[] args) {
        int[] original = {2, 4};
        int[] copy = Arrays.copyOf(original, original.length);
        copy[0] = 9;

        System.out.println(Arrays.toString(original));
        System.out.println(Arrays.toString(copy));
        System.out.println(original == copy);
    }
}
```

输出：

```text
[2, 4]
[9, 4]
false
```

`copyOf` 返回新的数组对象。对一维 `int[]` 而言，每个整数值被复制过去，因此修改副本不会影响原数组。

第二个参数决定新长度：

```java
int[] longer = Arrays.copyOf(original, 4);
System.out.println(Arrays.toString(longer));
```

输出 `[2, 4, 0, 0]`。长度变长时，新增的 `int` 位置用默认值 0 填充；长度变短时，多余元素被截断。

### 2. `clone()`

```java
int[] copy = original.clone();
```

对一维基本类型数组，这也会得到独立数组。今天优先掌握 `Arrays.copyOf`，因为它还能明确指定新长度。

### 3. `System.arraycopy`

```java
int[] source = {10, 20, 30, 40};
int[] target = new int[2];
System.arraycopy(source, 1, target, 0, 2);
System.out.println(Arrays.toString(target));
```

输出 `[20, 30]`。五个参数依次表示：源数组、源起点、目标数组、目标起点、复制数量。

## 🪆 三、二维数组为什么只复制外层

Java 的二维数组其实是“外层数组中的每个元素，再指向一行数组”。

```java
import java.util.Arrays;

public class ShallowCopyDemo {
    public static void main(String[] args) {
        int[][] a = {{1, 2}, {3}};
        int[][] b = Arrays.copyOf(a, a.length);

        b[0][1] = 9;
        b[1] = new int[]{7, 8};

        System.out.println(a[0][1]);
        System.out.println(a[1].length);
    }
}
```

输出：

```text
9
1
```

分两步看：

1. `b[0][1] = 9`：`a[0]` 和 `b[0]` 仍指向同一行数组，因此 `a[0][1]` 也变成 9。
2. `b[1] = new int[]{7, 8}`：这里只把 `b` 外层下标 1 改为指向新行，没有修改 `a[1]`，所以 `a[1].length` 仍是 1。

这叫浅复制：外层数组是新的，内层行数组仍共享。如果每一行都要独立，就逐行复制：

```java
int[][] copy = new int[a.length][];
for (int i = 0; i < a.length; i++) {
    copy[i] = Arrays.copyOf(a[i], a[i].length);
}
```

今天的周末项目是一维 `double[]`，所以一次 `Arrays.copyOf` 就足够。

## 💻 四、完整示例：保留原数组，反转副本

```java
import java.util.Arrays;
import java.util.Scanner;

public class ReverseCopy {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] original = new int[n];

        for (int i = 0; i < n; i++) {
            original[i] = sc.nextInt();
        }

        int[] reversed = Arrays.copyOf(original, original.length);
        for (int left = 0, right = reversed.length - 1;
             left < right;
             left++, right--) {
            int temp = reversed[left];
            reversed[left] = reversed[right];
            reversed[right] = temp;
        }

        System.out.println("Original: " + Arrays.toString(original));
        System.out.println("Reversed: " + Arrays.toString(reversed));
    }
}
```

输入 `4 10 20 30 40` 时输出：

```text
Original: [10, 20, 30, 40]
Reversed: [40, 30, 20, 10]
```

空数组 `n = 0` 时，`right` 是 -1，条件 `left < right` 一开始就为假，不会访问越界位置。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| `b = a` 会复制所有元素 | 它复制的是引用 | 用 `Arrays.copyOf` |
| `a == b` 比较元素内容 | 数组的 `==` 比较是否同一对象 | 内容可用 `Arrays.equals` |
| `copyOf` 只能复制相同长度 | 新长度可不同 | 变长补默认值，变短截断 |
| 二维数组复制后每一行都独立 | 普通复制只建立新外层数组 | 需要时逐行复制 |
| 替换 `b[1]` 会改变 `a[1]` | 两个外层数组的槽位独立 | 共享的是原来的行对象 |
| 空数组不能复制 | 可以复制为长度 0 的新数组 | 但不能访问 `[0]` |
