## 项目契约

`scoreSummary(scores, size)` 只读取 `[0, size)`，返回 `{数量, 总分, 最低分, 最高分}`。空有效区间返回 `{0,0,0,0}`；`size` 越界抛出 `IllegalArgumentException`。这个约定避免对空数组读取 `scores[0]`。

`textSummary(text)` 逐个 `char` 分类为字母、数字、空白、其他。`Character.isLetter/isDigit/isWhitespace` 比只比较 ASCII 范围更能表达分类意图。Java 的 `String.length()` 与 `charAt()` 按 UTF-16 代码单元工作；今天的练习只处理能由单个 `char` 表示的基础字符，不扩展到完整 Unicode 码点算法。

## 可运行实现

```java
import java.util.Arrays;

public class TextGradeStats {
    static int[] scoreSummary(int[] scores, int size) {
        if (size < 0 || size > scores.length) {
            throw new IllegalArgumentException("size out of range");
        }
        if (size == 0) return new int[] {0, 0, 0, 0};

        int sum = 0;
        int min = scores[0];
        int max = scores[0];
        for (int i = 0; i < size; i++) {
            int score = scores[i];
            sum += score;
            if (score < min) min = score;
            if (score > max) max = score;
        }
        return new int[] {size, sum, min, max};
    }

    static int[] textSummary(String text) {
        int letters = 0, digits = 0, spaces = 0, others = 0;
        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            if (Character.isLetter(ch)) letters++;
            else if (Character.isDigit(ch)) digits++;
            else if (Character.isWhitespace(ch)) spaces++;
            else others++;
        }
        return new int[] {letters, digits, spaces, others};
    }

    static void check(int[] actual, int[] expected) {
        if (!Arrays.equals(actual, expected)) {
            throw new AssertionError(Arrays.toString(actual));
        }
    }

    public static void main(String[] args) {
        check(scoreSummary(new int[] {70, 95, 70}, 3),
              new int[] {3, 235, 70, 95});
        check(scoreSummary(new int[] {}, 0),
              new int[] {0, 0, 0, 0});
        check(scoreSummary(new int[] {0}, 1),
              new int[] {1, 0, 0, 0});
        check(textSummary("Ab 2!中"),
              new int[] {3, 1, 1, 1});

        boolean rejected = false;
        try {
            scoreSummary(new int[] {80}, 2);
        } catch (IllegalArgumentException expected) {
            rejected = true;
        }
        if (!rejected) throw new AssertionError("invalid size must be rejected");

        System.out.println("java checks: OK");
    }
}
```

运行：`java TextGradeStats.java`。本次已核对正常、空数据、单元素、非法 `size` 与中英文混合文本，输出为 `java checks: OK`。

## 复杂度

- `scoreSummary`：时间 O(size)，除固定长度返回数组外额外工作空间 O(1)。
- `textSummary`：时间 O(text.length())，除固定长度返回数组外额外工作空间 O(1)。
- 两段先后执行时复杂度相加，不相乘。

## 易错点

- 空有效区间仍读取 `scores[0]`。
- 遍历整个容量而不是前 `size` 项。
- 用 `0` 初始化最低分，导致全为正数时结果错误。
- 非法 `size` 悄悄截断，掩盖调用错误。
- 忘记 `else if`，让一个字符进入多个类别。
