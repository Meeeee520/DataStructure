## 1. 先用四步法分析

面对一段 Java 代码，按顺序问：

1. **输入规模是什么？** 例如数组长度 `n = values.length`。
2. **核心操作执行多少次？** 写出 `1`、`log n`、`n`、`n(n-1)/2` 等次数。
3. **保留增长最快的项。** 忽略常数倍和低阶项。
4. **额外申请了什么空间？** 固定变量是 `O(1)`；长度随 `n` 增长的新数组是 `O(n)`。

## 2. 独立分析一组代码

```java
static int[] analyze(int[] values, int target) {
    int index = -1;
    int checks = 0;

    for (int i = 0; i < values.length; i++) {
        checks++;
        if (values[i] == target) {
            index = i;
            break;
        }
    }

    int pairs = 0;
    for (int i = 0; i < values.length; i++) {
        for (int j = i + 1; j < values.length; j++) {
            pairs++;
        }
    }
    return new int[]{index, checks, pairs};
}
```

设 `n = values.length`：

- 顺序查找最好情况：第一个元素命中，只检查 1 次，`O(1)`。
- 顺序查找最坏情况：最后命中或不存在，检查 `n` 次，`O(n)`。
- 不同位置对：`n(n-1)/2` 次，`O(n²)`。
- 两部分连续执行：`O(n) + O(n²) = O(n²)`。
- 除固定长度返回数组外只使用几个整数变量，额外工作空间是 `O(1)`。

## 3. 边界输入也属于验收

```java
System.out.println(java.util.Arrays.toString(
    analyze(new int[]{}, 7)
));
System.out.println(java.util.Arrays.toString(
    analyze(new int[]{7}, 7)
));
```

输出：

```text
[-1, 0, 0]
[0, 1, 0]
```

空数组不进入任何循环；单元素数组检查一次，但没有两个不同下标可组成一对。

## 4. 常见循环快速判断

| 代码形状 | 精确次数示意 | 复杂度 |
| --- | ---: | --- |
| `return values[0]` | 1 | `O(1)` |
| 一个完整遍历 | `n` | `O(n)` |
| 两个连续完整遍历 | `2n` | `O(n)` |
| 两层各执行 `n` 次 | `n²` | `O(n²)` |
| 只枚举 `i < j` | `n(n-1)/2` | `O(n²)` |
| 从 1 开始每轮翻倍 | 约 `log₂ n` | `O(log n)` |

这张表是判断起点，不是替代推理。真正验收时仍要说明循环边界。

## 🔁 D+1 主动回忆：循环结构

从 1 开始，每轮乘 2，直到达到或超过 `n`。为什么是 `O(log n)`？

<details><summary>查看答案</summary>

执行 `k` 轮后变量约为 `2ᵏ`；达到 `n` 所需的轮数满足 `2ᵏ ≥ n`，所以 `k` 约为 `log₂ n`。

</details>

## 🔁 D+7 主动回忆：数组入门

Java 数组创建后长度能否改变？读取 `values[i]` 前必须保证什么？

<details><summary>查看答案</summary>

数组长度创建后固定。有效下标必须满足 `0 <= i < values.length`，否则会抛出 `ArrayIndexOutOfBoundsException`。

</details>

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| 有两个循环就是 `O(n²)` | 连续循环相加，嵌套循环才可能相乘 | 画清执行关系 |
| 有 `break` 就是 `O(1)` | 只改善最好情况，最坏仍可能遍历全部 | 指明分析哪种情况 |
| `n(n-1)/2` 是 `O(n)` | 最高项是 `n²/2` | 写作 `O(n²)` |
| 返回新数组就一定是 `O(n)` 空间 | 本例返回长度固定为 3 | 看空间是否随 n 增长 |
| 空数组可访问下标 0 | 空数组没有任何有效下标 | 先检查长度 |
