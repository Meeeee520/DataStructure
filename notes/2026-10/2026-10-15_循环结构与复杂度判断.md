## 1. 连续循环：次数相加

```java
int work = 0;
for (int i = 0; i < n; i++) {
    work++;
}
for (int i = 0; i < n; i++) {
    work++;
}
```

两个循环各执行 `n` 次，总次数是 `n + n = 2n`。忽略常数倍后，时间复杂度仍是 `O(n)`。

判断关键不是“有几个循环”，而是这些循环**先后执行还是彼此嵌套**。

## 2. 嵌套循环：次数相乘

```java
int work = 0;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        work++;
    }
}
```

外层每执行一次，内层都完整执行 `n` 次；外层也执行 `n` 次，总次数是 `n × n = n²`，所以是 `O(n²)`。

如果内层是固定执行 10 次，总次数就是 `10n`，仍是 `O(n)`。不能只看到两层循环就直接下结论。

## 3. 三角形循环：少一半仍是平方量级

```java
int pairs = 0;
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        pairs++;
    }
}
```

它只枚举 `i < j` 的不同位置对。总次数是：

```text
(n - 1) + (n - 2) + ... + 1 + 0 = n(n - 1) / 2
```

虽然比完整的 `n²` 次少约一半，但最高增长项仍是 `n²`，所以时间复杂度仍是 `O(n²)`。

## 4. 每轮翻倍：`O(log n)`

```java
int rounds = 0;
for (int size = 1; size < n; size *= 2) {
    rounds++;
}
```

`size` 依次是 `1、2、4、8……`。执行 `k` 轮后大约到达 `2ᵏ`；要达到 `n`，轮数约为 `log₂ n`，因此是 `O(log n)`。

例如 `n = 8` 时，循环使用 `size = 1、2、4`，一共 3 轮。底数不会改变 Big O 的对数量级，通常简写为 `O(log n)`。

## 5. 提前结束与最坏情况

```java
static boolean contains(int[] values, int target) {
    for (int value : values) {
        if (value == target) {
            return true;
        }
    }
    return false;
}
```

目标在第一个位置时只检查一次；目标在最后一个位置或不存在时仍要检查 `n` 次。因此：

- 最好情况是 `O(1)`；
- 最坏情况是 `O(n)`。

只说“它会提前结束”不足以证明最坏情况更小。

## 6. 完整可运行示例

```java
public class LoopGrowthDemo {
    static int[] countWork(int n) {
        n = Math.max(0, n);

        int linear = 0;
        for (int i = 0; i < n; i++) {
            linear++;
        }

        int pairs = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                pairs++;
            }
        }

        int doubling = 0;
        int size = 1;
        while (size < n) {
            doubling++;
            if (size > n / 2) {
                break;
            }
            size *= 2;
        }
        return new int[]{linear, pairs, doubling};
    }

    public static void main(String[] args) {
        int[] result = countWork(8);
        System.out.println("Linear: " + result[0]);
        System.out.println("Pairs: " + result[1]);
        System.out.println("Doubling: " + result[2]);
    }
}
```

输出：

```text
Linear: 8
Pairs: 28
Doubling: 3
```

三个计数都只使用固定数量的整数变量，所以不计返回数组时，额外工作空间是 `O(1)`。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| 两个循环就是 `O(n²)` | 连续循环相加，嵌套循环才可能相乘 | 先画出执行关系 |
| 三角形循环只有一半工作量，所以是 `O(n)` | `n(n-1)/2` 的最高项仍是 `n²` | 忽略常数，不降低次数幂 |
| `size *= 2` 是 `O(n)` | 值每轮翻倍，只需约 `log₂ n` 轮 | 写出 1、2、4、8… |
| 有 `break` 就一定是 `O(1)` | 最坏时可能一直找不到 | 分别分析最好与最坏情况 |
| 循环次数就是空间复杂度 | 时间看执行次数，空间看额外存储 | 分开回答两个指标 |

### 练习 1 · 连续与嵌套

一个 `n` 次循环后接一个 `n²` 次嵌套循环，整体复杂度是什么？

<details><summary>查看答案</summary>

是 `O(n²)`。总工作量为 `n + n²`，保留增长更快的最高阶项。

</details>

### 练习 2 · 翻倍次数

`n = 16` 时，`size` 从 1 开始且每轮乘 2，在 `size < n` 时执行。循环体执行几次？

<details><summary>查看答案</summary>

执行 4 次，对应 `size = 1、2、4、8`。

</details>

### 练习 3 · 最坏情况

顺序查找使用 `return` 提前结束。目标不存在时的时间复杂度是什么？

<details><summary>查看答案</summary>

仍是 `O(n)`，因为必须检查全部 `n` 个元素才能确认目标不存在。

</details>
