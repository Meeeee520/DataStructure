## 1. 创建与访问

```java
double[][] scores = {
    {60, 80},
    {90, 100}
};

System.out.println(scores[0][1]);
System.out.println(scores.length);
System.out.println(scores[0].length);
```

输出：

```text
80.0
2
2
```

`scores[0][1]` 表示第 1 行、第 2 列。若约定“学生是行、课程是列”，它就是第 1 位学生第 2 门课的成绩。

- `scores.length`：行数。
- `scores[i].length`：第 `i` 行的列数。
- 下标都从 0 开始。

## 2. 规则矩形与不规则数组

```java
int[][] rectangle = new int[3][2];
int[][] jagged = {
    {1, 2, 3},
    {4},
    {5, 6}
};
```

Java 的二维数组是数组的数组，所以每行长度可以不同。遍历不规则数组时不要统一使用 `a[0].length`：

```java
for (int i = 0; i < jagged.length; i++) {
    for (int j = 0; j < jagged[i].length; j++) {
        System.out.print(jagged[i][j] + " ");
    }
    System.out.println();
}
```

## 3. 按行与按列遍历

按学生查看各科成绩：外层是行 `i`，内层是列 `j`。

```java
for (int i = 0; i < scores.length; i++) {
    for (int j = 0; j < scores[i].length; j++) {
        System.out.println(scores[i][j]);
    }
}
```

按课程求平均：先选课程列，再遍历每个学生行。

```java
for (int j = 0; j < scores[0].length; j++) {
    double total = 0;
    for (int i = 0; i < scores.length; i++) {
        total += scores[i][j];
    }
    System.out.println(total / scores.length);
}
```

上面假设数组是非空规则矩形。真实程序必须先处理行数或列数为 0，才能访问 `scores[0]`。

## 4. 完整示例：每门课程平均分

```java
import java.util.Locale;
import java.util.Scanner;

public class CourseReport {
    public static void main(String[] args) {
        Locale.setDefault(Locale.US);
        Scanner sc = new Scanner(System.in);
        int students = sc.nextInt();
        int courses = sc.nextInt();

        if (students <= 0 || courses <= 0) {
            System.out.println("暂无成绩");
            return;
        }

        double[][] scores = new double[students][courses];
        for (int i = 0; i < students; i++) {
            for (int j = 0; j < courses; j++) {
                scores[i][j] = sc.nextDouble();
            }
        }

        for (int j = 0; j < courses; j++) {
            double total = 0;
            for (int i = 0; i < students; i++) {
                total += scores[i][j];
            }
            System.out.printf("课程%d平均分：%.2f%n",
                              j + 1, total / students);
        }
    }
}
```

输入：

```text
3 2
60 80
80 90
100 100
```

输出：

```text
课程1平均分：80.00
课程2平均分：90.00
```

每开始一门新课程，`total` 都必须重新设为 0。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| `a.length` 是总元素数 | 它是外层行数 | 每行长度看 `a[i].length` |
| 每行必定等长 | Java 允许不规则二维数组 | 遍历用 `a[i].length` |
| `scores[1][0]` 是第 1 人第 2 科 | 下标从 0 开始 | 它是第 2 人第 1 科 |
| 两层循环顺序不影响含义 | 顺序决定按行还是按列 | 先明确统计对象 |
| `total` 可以只初始化一次 | 每列应有独立总和 | 放在课程外层循环内部 |
| 零行时可访问 `scores[0]` | 下标 0 不存在 | 先检查尺寸 |
