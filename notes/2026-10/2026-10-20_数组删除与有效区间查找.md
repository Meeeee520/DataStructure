## 1. 查找只看有效数据

容量 5、size 为 3、底层数组 `[4, 7, 7, 0, 0]` 中，目标 7 首次出现于下标 1；目标 0 不存在于有效区间，不能把空余位置的默认 0 当作命中。

从 0 开始检查到 `size - 1`，命中立刻返回下标，未命中返回 -1。这是对已有顺序查找的复用，不需要先排序。

## 2. 找到以后，再按位置删除

删除上述第一个 7（下标 1）时，右侧有效数据左移一格，原有效尾清为 0，调用者将 size 减为 2。结果有效序列为 `[4, 7]`，不是把全部 7 都删掉。

删除下标 index 需要移动 `size - index - 1` 项。尾部删除移动 0 次，依然成功；失败返回 -1，不能改数组或长度。清尾是本练习的约定，0 仍然可以是真实有效数据。

## 3. 可运行的最小组合

保存为 `ArrayDeleteSearch.java`，先运行 `javac ArrayDeleteSearch.java`，再运行 `java ArrayDeleteSearch`。输入容量、有效长度、有效数据和查找目标；所有输入记号按整数提供。

```java
import java.util.Arrays;
import java.util.Scanner;

public class ArrayDeleteSearch {
    // 两个方法都假设 values 非 null，且 0 <= size <= values.length。
    static int findFirst(int[] values, int size, int target) {
        for (int i = 0; i < size; i++) {
            if (values[i] == target) {
                return i;
            }
        }
        return -1;
    }

    static int deleteAt(int[] values, int size, int index) {
        if (index < 0 || index >= size) {
            return -1;
        }
        int shifts = 0;
        for (int i = index; i < size - 1; i++) {
            values[i] = values[i + 1];
            shifts++;
        }
        values[size - 1] = 0;
        return shifts;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int capacity = sc.nextInt();
        int size = sc.nextInt();
        if (capacity < 0 || size < 0 || size > capacity) {
            System.out.println("Invalid model");
            return;
        }
        int[] values = new int[capacity];
        for (int i = 0; i < size; i++) {
            values[i] = sc.nextInt();
        }
        int target = sc.nextInt();
        int index = findFirst(values, size, target);
        int shifts = deleteAt(values, size, index);
        if (shifts >= 0) {
            size--;
        }
        System.out.println("Found: " + index);
        System.out.println("Shifts: " + shifts);
        System.out.println("Size: " + size);
        System.out.println("Values: " + Arrays.toString(Arrays.copyOf(values, size)));
    }
}
```

输入：

```text
5 3
4 7 7
7
```

输出：

```text
Found: 1
Shifts: 1
Size: 2
Values: [4, 7]
```

空序列输入 `2 0 7` 时输出：

```text
Found: -1
Shifts: -1
Size: 0
Values: []
```

找不到时把 -1 交给 `deleteAt`，它先检查位置并立即返回，既不访问负下标，也不会让 size 变成 -1。这里沿用已有 deleteAt 的返回约定：返回移动次数，不是新长度；只有调用者更新自己的整数变量。

## 4. 两段线性工作，不是自动变成平方

查找最坏检查 n 个元素，删除最多移动 n−1 个元素；先后执行总成本仍为 O(n)，不是 O(n²)。只有代码结构和执行次数确实形成相应增长时才能下结论，不能只数“出现了两个循环”。

核心方法只使用固定数量变量，额外工作空间 O(1)。用于显示的 `Arrays.copyOf(values, size)` 会建立 O(n) 副本，这部分另外计算。输入数组本身的空间与容量有关。

| 情况 | 查找/删除行为 |
| --- | --- |
| 重复目标 | 首次命中即停，只删第一个 |
| 尾部目标或单元素 | 删除移动 0 次，但 size 仍减 1 |
| 目标不存在 | 返回 -1，数组与 size 保持原样 |
| 有效数据含 0 | 可以正常命中；空余容量的 0 不参与查找 |
| size 为 0 | 查找循环不进入，删除失败，不越界 |
| 删除 index == size | 属于无效位置，不能与合法尾插混淆 |

## ⚠️ 易错点

| 错误 | 修正 |
| --- | --- |
| 用 length 而不是 size 查找 | 仅扫描有效区间 |
| 遇到相同值继续覆盖答案 | 首次命中立即返回 |
| 删除允许 index == size | 删除必须 index < size；这与插入不同 |
| 没找到仍无条件 size-- | 仅在删除返回值非负时减少长度 |
| 倒序做删除左移 | 左移应正序，防止覆盖还要读取的值 |
| 两个连续循环就断言 O(n²) | 分别数执行次数，再相加 |
