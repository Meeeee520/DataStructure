## 分步任务

### 1. 先约定返回结果

- [ ] `linearSearch` 返回长度为 2 的 `int` 数组：第 0 项是第一次匹配下标，找不到为 `-1`；第 1 项是实际检查次数。

**为什么 / 提示**：把 `index` 的默认值想成 `-1`；合法下标从 0 开始。

**会用到**：返回约定、数组。

### 2. 从左到右逐个比较

- [ ] 循环条件使用 `i < ids.length`；每比较一个元素就增加 `checks`。字符串比较使用 `ids[i].equals(target)`，第一次匹配立刻返回。

**为什么 / 提示**：`String` 内容比较不能用 `==`；`return` 会结束本次方法调用。

**会用到**：顺序查找、`equals`、提前返回。

### 3. 验证重复、缺失和空数组

- [ ] 运行四组样例。解释为什么重复目标返回第一个位置，目标缺失检查 `n` 次，空数组检查 0 次。

**为什么 / 提示**：不要在空数组上访问 `ids[0]`；让循环自然执行零次。

**会用到**：边界测试、`O(n)` 直觉。

- 为什么目标不存在时顺序查找的最坏成本是 `O(n)`？
- 为什么用 `-1` 表示没找到？

<details>
<summary>完成后再打开：参考实现与解释</summary>

```java
import java.util.Scanner;

public class StudentIdSearch {
    static int[] linearSearch(String[] ids, String target) {
        int checks = 0;
        for (int i = 0; i < ids.length; i++) {
            checks++;
            if (ids[i].equals(target)) {
                return new int[]{i, checks};
            }
        }
        return new int[]{-1, checks};
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        if (n < 0) {
            n = 0;
        }
        String[] ids = new String[n];
        for (int i = 0; i < n; i++) {
            ids[i] = sc.next();
        }
        String target = sc.next();
        int[] result = linearSearch(ids, target);
        System.out.println("Index: " + result[0]);
        System.out.println("Checks: " + result[1]);
    }
}
```

- 循环只访问 `0` 到 `length - 1`，空数组时自然执行零次。
- 每次真正比较一个学号才增加 `checks`，第一次匹配立即返回。
- `String` 使用 `equals` 比较内容。

</details>
