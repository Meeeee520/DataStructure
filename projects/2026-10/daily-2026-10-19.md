## 起始代码

```java
import java.util.Arrays;
import java.util.Scanner;

public class InsertionPractice {
    // 前提：values 非 null，0 <= size <= values.length。
    static int insertAt(int[] values, int size, int index, int value) {
        return -1;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int capacity = sc.nextInt();
        int size = sc.nextInt();
        if (capacity < 0 || size < 0 || size > capacity) {
            System.out.println("Invalid model");
            return;
        }
        int[] values = new int[capacity];
        for (int i = 0; i < size; i++) {
            values[i] = sc.nextInt();
        }
        int index = sc.nextInt();
        int value = sc.nextInt();
        int shifts = insertAt(values, size, index, value);
        if (shifts >= 0) {
            size++;
        }
        System.out.println("Shifts: " + shifts);
        System.out.println("Size: " + size);
        System.out.println("Values: " + Arrays.toString(Arrays.copyOf(values, size)));
    }
}
```

## 分步任务

### 1. 先写成功与失败的条件

保持 0<=size<=capacity；容量已满或 index 不在 0..size 时返回 -1，不能改数组。

提示：这是今日第五题同一方法，不需要重复实现两次。

### 2. 从右向左腾出位置

倒序右移并计数，写入新值；成功时由 main 增加 size。

提示：尾插移动 0 次，但仍为成功。

### 3. 用固定输出核对

验证中间、空、尾部、满容量、非法位置与非法模型；说明最好 O(1)、最坏 O(n)。

提示：这项短练习已计入今天 25–35 分钟预算，不额外叠加。

## 成本与典型错误

核心方法移动 size-index 次：尾插 O(1)，首插最坏 O(n)，额外工作空间 O(1)。用于显示的 Arrays.copyOf 另外占 O(n) 空间。

- 插入允许 index==size，但不能 index>size。
- 右移必须倒序，避免覆盖尚未搬移的值。
- 失败先返回 -1，不能留下部分修改。
- 返回 0 仍为成功，调用者需要增加 size。

## 主动回忆

- 读取元素与插入位置的上界为什么不同？
  <details><summary>查看答案</summary>
读取必须 index<size；插入允许 index==size 表示追加，但还要有容量。

- 返回 0 为什么仍应增加 size？
  <details><summary>查看答案</summary>
0 表示无需搬移的成功尾插；只有 -1 表示失败。

- 核心插入与展示副本的额外空间有什么区别？

</details>

## 参考实现

<details><summary>独立完成并自测后再展开</summary>

```java
import java.util.Arrays;
import java.util.Scanner;

public class InsertionPractice {
    // 前提：values 非 null，0 <= size <= values.length。
    static int insertAt(int[] values, int size, int index, int value) {
        if (size == values.length || index < 0 || index > size) {
            return -1;
        }
        int shifts = 0;
        for (int i = size; i > index; i--) {
            values[i] = values[i - 1];
            shifts++;
        }
        values[index] = value;
        return shifts;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int capacity = sc.nextInt();
        int size = sc.nextInt();
        if (capacity < 0 || size < 0 || size > capacity) {
            System.out.println("Invalid model");
            return;
        }
        int[] values = new int[capacity];
        for (int i = 0; i < size; i++) {
            values[i] = sc.nextInt();
        }
        int index = sc.nextInt();
        int value = sc.nextInt();
        int shifts = insertAt(values, size, index, value);
        if (shifts >= 0) {
            size++;
        }
        System.out.println("Shifts: " + shifts);
        System.out.println("Size: " + size);
        System.out.println("Values: " + Arrays.toString(Arrays.copyOf(values, size)));
    }
}
```

- 复用每日第五题的方法，不另建大型功能。
- 先校验位置，再倒序移动，保持有效数据连续。
- 返回的是移动次数；main 仅在非负时更新 size。
- 展示副本的开销单独分析，不冒充核心方法的 O(1) 额外空间。

</details>
