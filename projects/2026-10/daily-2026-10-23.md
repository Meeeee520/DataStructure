## 目标

复用当日验收题，统计有效区间相邻对和小写元音；不额外增加项目。

## 步骤

1. **相邻对计数**：只扫描数组前size项，从i=1比较前一项。

2. **小写元音计数**：逐char判断a/e/i/o/u，不改变大小写契约。

3. **独立验收**：运行正常、空、单元素和非法模型。

## 起始代码

保存为 `ArrayStringCheck.java`，运行 `java ArrayStringCheck.java`。

```java
import java.util.Arrays;
import java.util.Scanner;

public class ArrayStringCheck {
    static int adjacentEquals(int[] values, int size) {
        return 0;
    }

    static int countLowercaseVowels(String text) {
        return 0;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int capacity = sc.nextInt();
        int size = sc.nextInt();
        if (capacity < 0 || size < 0 || size > capacity) {
            System.out.println("Invalid model");
            return;
        }
        int[] values = new int[capacity];
        for (int i = 0; i < size; i++) values[i] = sc.nextInt();
        sc.nextLine();
        String text = sc.nextLine();
        System.out.println("Adjacent: " + adjacentEquals(values, size));
        System.out.println("Vowels: " + countLowercaseVowels(text));
        System.out.println("Active: " + Arrays.toString(Arrays.copyOf(values, size)));
    }
}
```

## 参考实现

<details><summary>独立尝试后查看</summary>

```java
import java.util.Arrays;
import java.util.Scanner;

public class ArrayStringCheck {
    static int adjacentEquals(int[] values, int size) {
        int count = 0;
        for (int i = 1; i < size; i++) {
            if (values[i] == values[i - 1]) count++;
        }
        return count;
    }

    static int countLowercaseVowels(String text) {
        int count = 0;
        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') {
                count++;
            }
        }
        return count;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int capacity = sc.nextInt();
        int size = sc.nextInt();
        if (capacity < 0 || size < 0 || size > capacity) {
            System.out.println("Invalid model");
            return;
        }
        int[] values = new int[capacity];
        for (int i = 0; i < size; i++) values[i] = sc.nextInt();
        sc.nextLine();
        String text = sc.nextLine();
        System.out.println("Adjacent: " + adjacentEquals(values, size));
        System.out.println("Vowels: " + countLowercaseVowels(text));
        System.out.println("Active: " + Arrays.toString(Arrays.copyOf(values, size)));
    }
}
```
</details>
