# 🛠️ 成绩数组扩容器

> 项目 ID：`daily-2026-10-16` · Java 可选小练习 · 建议用时约 20 分钟

## 项目目标

从固定容量数组开始，追加成绩时若空间不足，就创建两倍容量的新数组并复制旧值。观察一次扩容为什么需要 `O(n)` 时间。

## 输入输出示例

输入：

```text
1
3
60 80 100
```

输出：

```text
Size: 3
Capacity: 4
Values: [60, 80, 100]
```

## 分步完成

1. 创建初始数组并用 `size` 记录有效长度。
2. `size == values.length` 时调用 `grow`。
3. 先保证容量，再写入 `values[size]`。
4. 输出时只展示前 `size` 个有效元素。
5. 运行容量 0、空数据和刚好够用的边界样例。

## 参考实现

<details><summary>完成后再展开</summary>

```java
import java.util.Arrays;
import java.util.Scanner;

public class DynamicScoreArray {
    static int[] grow(int[] values) {
        int newCapacity = values.length == 0 ? 1 : values.length * 2;
        return Arrays.copyOf(values, newCapacity);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int capacity = Math.max(0, sc.nextInt());
        int n = Math.max(0, sc.nextInt());
        int[] values = new int[capacity];
        int size = 0;
        for (int i = 0; i < n; i++) {
            if (size == values.length) {
                values = grow(values);
            }
            values[size++] = sc.nextInt();
        }
        System.out.println("Size: " + size);
        System.out.println("Capacity: " + values.length);
        System.out.println("Values: " + Arrays.toString(Arrays.copyOf(values, size)));
    }
}
```
