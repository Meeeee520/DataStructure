## 复杂度与常见错误

只复用笔记和第五题，不增加工作日大型项目。

空串自然跳过，空格保留，大写A不计入小写a。

按UTF-16 char单元处理，不声称可见字符计数。

不要用<=length()；不要trim后声称统计了原文本；String.length()计UTF-16单元，不是可见字符数。

<details><summary>参考实现（独立尝试后打开）</summary>

```java
import java.util.Scanner;

public class TextScan {
    // 前提：text 非 null；本练习按 UTF-16 char 单元处理。
    static int countChar(String text, char target) {
        int count = 0;
        for (int i = 0; i < text.length(); i++) {
            if (text.charAt(i) == target) {
                count++;
            }
        }
        return count;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String text = sc.nextLine();
        System.out.println("Length: " + text.length());
        System.out.println("a: " + countChar(text, 'a'));
    }
}

```

</details>
