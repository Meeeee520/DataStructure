# 🛠️ 循环增长观察器

> 项目 ID：`daily-2026-10-15` · Java 可选小练习 · 建议用时约 20 分钟

## 项目目标

输入一个规模 `n`，用真实计数比较三种循环：

- 完整循环：`n` 次，对应 `O(n)`；
- 枚举所有 `i < j` 的位置对：`n(n-1)/2` 次，对应 `O(n²)`；
- 从 1 开始每轮翻倍：约 `log₂ n` 次，对应 `O(log n)`。

## 分步完成

1. 用 `Math.max(0, n)` 处理负数输入。
2. 写一个执行 `n` 次的循环，统计 `linear`。
3. 用 `i` 和从 `i + 1` 开始的 `j` 统计 `pairs`。
4. 让 `size` 从 1 开始翻倍，统计到达 `n` 前的轮数。
5. 运行 `n = 8、0、1、2`，核对正常与边界输出。

<details><summary>提示：如何避免翻倍时整数溢出？</summary>

本轮计数后，如果 `size > n / 2`，下一次翻倍已经会达到或超过 `n`，可直接 `break`，无需真的计算可能溢出的 `size * 2`。

</details>

## 参考实现

<details><summary>完成后再展开</summary>

```java
import java.util.Scanner;

public class LoopGrowth {
    static int[] countWork(int n) {
        n = Math.max(0, n);

        int linear = 0;
        for (int i = 0; i < n; i++) {
            linear++;
        }

        int pairs = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                pairs++;
            }
        }

        int doubling = 0;
        int size = 1;
        while (size < n) {
            doubling++;
            if (size > n / 2) {
                break;
            }
            size *= 2;
        }
        return new int[]{linear, pairs, doubling};
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int[] result = countWork(sc.nextInt());
        System.out.println("Linear: " + result[0]);
        System.out.println("Pairs: " + result[1]);
        System.out.println("Doubling: " + result[2]);
    }
}
```

</details>
