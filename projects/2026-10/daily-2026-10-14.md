# 🛠️ 成绩扫描复杂度观察器

> 项目 ID：`daily-2026-10-14` · Java 可选小练习 · 建议用时约 20 分钟

## 项目目标

用计数器观察两种工作量：

- 完整扫描 `n` 个成绩：检查 `n` 次，属于 `O(n)`；
- 比较所有不同下标对：检查 `n(n-1)/2` 次，属于 `O(n²)`。

## 分步完成

1. 用一个 for-each 循环统计达标人数；每检查一个成绩，`linearChecks++`。
2. 用 `i` 和从 `i + 1` 开始的 `j` 统计所有不同位置对。
3. 返回 `{passed, linearChecks, pairChecks}`。
4. 运行 `n = 0`、`n = 1` 与 `n = 4` 三类边界样例。

<details><summary>提示：n = 4 时为什么是 6 对？</summary>

下标 0 能与后面 3 个位置配对，下标 1 能与后面 2 个位置配对，下标 2 能与后面 1 个位置配对：`3 + 2 + 1 = 6`。

</details>

## 参考实现

<details><summary>完成后再展开</summary>

```java
import java.util.Scanner;

public class ScoreComplexity {
    static int[] analyze(int[] scores, int minimum) {
        int passed = 0;
        int linearChecks = 0;
        for (int score : scores) {
            linearChecks++;
            if (score >= minimum) {
                passed++;
            }
        }

        int pairChecks = 0;
        for (int i = 0; i < scores.length; i++) {
            for (int j = i + 1; j < scores.length; j++) {
                pairChecks++;
            }
        }
        return new int[]{passed, linearChecks, pairChecks};
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = Math.max(0, sc.nextInt());
        int[] scores = new int[n];
        for (int i = 0; i < n; i++) {
            scores[i] = sc.nextInt();
        }
        int minimum = sc.nextInt();
        int[] result = analyze(scores, minimum);
        System.out.println("Passed: " + result[0]);
        System.out.println("Linear checks: " + result[1]);
        System.out.println("Pair checks: " + result[2]);
    }
}
```
