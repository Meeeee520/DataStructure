## 起始代码

```java
import java.util.Arrays;
import java.util.Scanner;

public class ArrayDeleteSearch {
    // 两个方法都假设 values 非 null，且 0 <= size <= values.length。
    static int findFirst(int[] values, int size, int target) {
        return -1;
    }

    static int deleteAt(int[] values, int size, int index) {
        return -1;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int capacity = sc.nextInt();
        int size = sc.nextInt();
        if (capacity < 0 || size < 0 || size > capacity) {
            System.out.println("Invalid model");
            return;
        }
        int[] values = new int[capacity];
        for (int i = 0; i < size; i++) {
            values[i] = sc.nextInt();
        }
        int target = sc.nextInt();
        int index = findFirst(values, size, target);
        int shifts = deleteAt(values, size, index);
        if (shifts >= 0) {
            size--;
        }
        System.out.println("Found: " + index);
        System.out.println("Shifts: " + shifts);
        System.out.println("Size: " + size);
        System.out.println("Values: " + Arrays.toString(Arrays.copyOf(values, size)));
    }
}
```

## 分步任务

### 1. 只查有效区间

从 0 到 size-1 查找，首个匹配立即返回，未命中返回 -1。

提示：空余容量中的 0 不参与查找。

### 2. 安全地左移删除

先检查位置再左移与清尾；返回移动次数，调用者仅在非负时 size--。

提示：删除尾部返回 0，仍然成功。

### 3. 验证重复、空和真实 0

运行固定测试并解释两段连续线性成本仍为 O(n)，不重复做一套项目。

提示：本页是每日第五题的可选展示。

## 边界与成本

找不到返回 -1，不修改状态；重复目标只删除首个。查找加删除最坏 O(n)，核心额外工作空间 O(1)，展示副本另占 O(n)。

常见错误：遍历全部 capacity、把 index==size 当作合法删除、零次移动不减 size、把两个连续循环误判为平方复杂度。本页不新增大型项目或后续数据结构。

## 折叠参考实现

<details><summary>完成尝试与测试后再展开</summary>

```java
import java.util.Arrays;
import java.util.Scanner;

public class ArrayDeleteSearch {
    // 两个方法都假设 values 非 null，且 0 <= size <= values.length。
    static int findFirst(int[] values, int size, int target) {
        for (int i = 0; i < size; i++) {
            if (values[i] == target) {
                return i;
            }
        }
        return -1;
    }

    static int deleteAt(int[] values, int size, int index) {
        if (index < 0 || index >= size) {
            return -1;
        }
        int shifts = 0;
        for (int i = index; i < size - 1; i++) {
            values[i] = values[i + 1];
            shifts++;
        }
        values[size - 1] = 0;
        return shifts;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int capacity = sc.nextInt();
        int size = sc.nextInt();
        if (capacity < 0 || size < 0 || size > capacity) {
            System.out.println("Invalid model");
            return;
        }
        int[] values = new int[capacity];
        for (int i = 0; i < size; i++) {
            values[i] = sc.nextInt();
        }
        int target = sc.nextInt();
        int index = findFirst(values, size, target);
        int shifts = deleteAt(values, size, index);
        if (shifts >= 0) {
            size--;
        }
        System.out.println("Found: " + index);
        System.out.println("Shifts: " + shifts);
        System.out.println("Size: " + size);
        System.out.println("Values: " + Arrays.toString(Arrays.copyOf(values, size)));
    }
}
```

- 复用既有 findFirst 与 deleteAt 语义。
- 失败先返回，不修改数组或有效长度。
- 参考实现使用固定数量工作变量，展示 copyOf 副本另占 O(n)。

</details>
